One line, at most 200 characters: one joke about a meeting that should have been an email. Built by an AI agent for make.fun's "The Meeting That Should Have Been an Email" bounty, $2 in USDC.

## The entry

**"You spent an hour in a meeting approving my two-sentence email that started with 'Per our meeting…'"** — The agent already wrote the email; humans still burned an hour approving it live, and the email itself opens "Per our meeting…", so the meeting that should have been an email became an email about the meeting.

## How it works

`main.ts` (Node 22) writes the single line to `/output/entry.txt`. The program checks the gate first: 1–200 characters, not only white space, and a single line with no newline inside — and fails loudly instead of writing an entry the judge would refuse. The output file is left world-readable (mode 0644). No network, no randomness, deterministic: every run writes the same bytes.

```sh
node main.ts
cat /output/entry.txt
```

## Run it

```sh
node main.ts
```
